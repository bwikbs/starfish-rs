# E4-M3 — Events + timers + the load sequence: run-to-quiescence then render (design note)

Scope (per `docs/ROADMAP-epic4.md` + the M3 brief): the **final** JavaScript milestone. Since
this is a one-shot renderer (no live interaction loop), the value is **run-to-quiescence then
render**: after the page's `<script>`s run (E4-M1/M2 flow), fire `DOMContentLoaded` (on
`document`) + `load` (on `window`), drain **bounded** `setTimeout`/`setInterval` callbacks and
Boa Promise microtasks — letting them mutate the DOM — and **then** style / layout / paint the
**final** DOM state. APIs added:

- `addEventListener` / `removeEventListener` / `dispatchEvent` on every DOM node (and on
  `document` / `window`); a minimal `Event` object (`{type, target, currentTarget,
  defaultPrevented, preventDefault(), stopPropagation()}`); **target-phase** firing with an
  **optional cheap bubble** up the parent chain.
- `DOMContentLoaded` on `document` and `load` on `window`, fired after parsing + initial scripts.
- `setTimeout` / `setInterval` / `clearTimeout` / `clearInterval`, drained against a **bounded
  virtual clock** (virtual time, no real sleeping; capped callback count + capped virtual time so
  `setInterval` can't loop forever).
- inline `on*` handler attributes (`<body onload=…>`, `<button onclick=…>`) — **decided IN, cheap**
  (compile the attribute string as a listener; §6).

This note is pinned to the **real** current source (M1/M2 files quoted as read) and to the **exact
Boa 0.21.1 API** verified against the crate at
`~/.cargo/registry/src/index.crates.io-*/boa_engine-0.21.1` (signatures quoted in §0). The
companion ANALYSIS agent's findings are the authority for any Boa call; this note's calls are the
**verified 0.21.1 shapes**.

Guiding rule (project CLAUDE.md "Simplicity First / Surgical Changes"): **target-phase events +
optional bubble + a bounded virtual-time timer drain + microtasks**, nothing more. Defer capture
phase precision, `passive`, `requestAnimationFrame` precision, real input events, event default
actions. The only `run_scripts` body change is adding the **run-to-quiescence loop before the
clone-out**; `render_document` and the M1/M2 ownership seam are untouched. Deviations / non-goals
are §8.

- `wrap_node(id, ctx) -> JsResult<JsObject>` / `wrap_opt(Option<NodeId>, ctx) -> JsResult<JsValue>`

- `globals::install(ctx, &shared, base)` (`globals.rs:23`) calls `dom::install` and registers

  (`window === globalThis`, `globals.rs:26`) — §1.4 explains how `window.addEventListener`/`load`
  attaches to a distinguished key (the arena **root** `NodeId`, shared with `document`, or a

### 0.2 `run_scripts` (`crates/js/src/lib.rs:77`) — the integration point

```rust
pub fn run_scripts(doc: &mut Document, base: &Url, loader: &dyn ResourceLoader) -> ScriptOutcome {
    let (scripts, load_errors) = collect::collect_scripts(doc, base, loader);
    if scripts.is_empty() && load_errors.is_empty() { return ScriptOutcome::default(); }
    let shared = Rc::new(RefCell::new(std::mem::take(doc)));
    let mut ctx = Context::default();
    let console_sink = console::install(&mut ctx);
    globals::install(&mut ctx, &shared, base);
    // ... eval each script (errors captured, non-fatal) ...
    // >>> E4-M3: THE RUN-TO-QUIESCENCE LOOP GOES HERE, BEFORE drop(ctx) <<<
    drop(ctx);
    let recovered = match Rc::try_unwrap(shared) { Ok(c)=>c.into_inner(), Err(rc)=>rc.borrow().clone() };
    *doc = recovered;
    ScriptOutcome { console: console_sink.take(), errors, executed }
}
```

The M3 loop (§4) runs **after the script eval loop, before `drop(ctx)`** — it borrows `&mut ctx`
and reads `DomState`/timer queue from `ctx.realm().host_defined()`. The **clone-out + no-panic
guarantees are unchanged**: every timer/listener callback mutates the same `shared` arena, and
when the loop finishes, `drop(ctx)` → `try_unwrap`/clone recovers the final post-quiescence arena.
There is **no early-return-skips-quiescence problem**: if there are zero `<script>`s, the early
return at the top still applies (no listeners could have been registered without a script;
inline `on*` handlers are only fired if such an element exists — see §6.3 for the no-script
edge: an inline `<body onload>` with no `<script>` still needs the loop, handled in §6.3).

### 0.3 Boa 0.21.1 — exact API surface used (verified against crate source)

- **Invoke a stored callback:** `JsObject::call(this: &JsValue, args: &[JsValue], ctx: &mut Context)
  -> JsResult<JsValue>` (`src/object/operations.rs:394`). This is the **simplest** call path — no
  generic `TypedJsFunction` machinery. We store callables as `JsObject` (or `JsFunction`); both
  call via this. A thrown value comes back as `Err(JsError)` → **caught, non-fatal** (§7).
- **Callable identity / equality:** `JsObject` impls `PartialEq` + `Eq` + `Hash` by **pointer
  identity** (`src/object/jsobject.rs:887` `eq = JsObject::equals`; `:894` `Hash` via
  `ptr::hash`). So `removeEventListener` matches the **same** function object reference, and
  duplicate-listener dedup is `Vec::contains` / `HashSet` over `JsObject` — exact spec identity.
- **`JsFunction`** lives at `boa_engine::object::builtins::JsFunction` (`src/lib.rs` re-exports
  `builtins`); it is `#[derive(Clone, Trace, Finalize)]` (`jsfunction.rs:115`), wraps a callable
  `JsObject`. `JsFunction::from_object(o) -> Option<Self>` checks `is_callable` (`:149`). We can
  store **either** `JsObject` (after an `is_callable()` check) **or** `JsFunction` — this note uses
  `JsObject` for listeners/timer callbacks (one fewer wrapper; identity + `call` both work on
  `JsObject`), validated callable at registration.
- **Drain Promise microtasks:** `Context::run_jobs(&mut self) -> JsResult<()>`
  (`src/context/mod.rs:485`) runs all queued jobs (the promise-reaction microtask queue). Boa
  **enqueues promise jobs itself** during `eval`/`call`; we do **not** enqueue anything — we just
  call `ctx.run_jobs()` to drain them. (`enqueue_job(Job)` at `:479` exists but is **not needed**:
  timers are OUR queue, not Boa jobs — §3.2 rationale.) `run_jobs()` returning `Err` is caught,
  non-fatal.
- **Register a global native fn** (`setTimeout` etc.): `Context::register_global_callable(name:
  JsString, length: usize, body: NativeFunction) -> JsResult<()>` (`src/context/mod.rs:280`), or
  `register_global_property` with a built function. `NativeFunction::from_copy_closure_with_captures`
  (already used in `console.rs`, `style.rs`) lets the closure capture a `Trace`-able handle.
- **Host-defined mutation:** `ctx.realm().host_defined()` returns `GcRef<HostDefined>` (shared
  borrow); `…host_defined_mut()` returns `GcRefMut` (`src/realm.rs:128,142`). `HostDefined::get::<T>()
  -> Option<&T>` / `get_mut::<T>()` / `insert` / `remove` (`src/host_defined.rs:42,59,67,76`).
  **Because closures hold only a shared `&DomState` (via `get`), the listener/timer collections
  inside `DomState` must use `GcRefCell` for interior mutability** — exactly like the existing
  `cache: GcRefCell<HashMap<…>>` (§1.1, §3.1). A native fn cannot call `host_defined_mut()` while a
  `host_defined()` borrow is live, so we **snapshot what we need out of `DomState` then drop the
  borrow** before re-entering JS (§1.5 borrow discipline).
- `JsValue::null()`/`undefined()`, `JsNativeError::typ().with_message(..).into()`, `JsString`,
  `js_string!`, `JsObject::from_proto_and_data` — all as in M1/M2.

## 1. Event-listener storage + `addEventListener`/`removeEventListener`

### 1.1 Where listeners live — extend `DomState` (host-defined, GC-traced)

Listeners are callable `JsObject`s (GC-managed). They must be **GC-traced** so they stay rooted
across the quiescence loop (otherwise Boa could collect a listener registered in a script before
`load` fires). `DomState` is already `#[derive(Trace, Finalize, JsData)]` and already traces a
`GcRefCell<HashMap<…, JsObject>>` (the wrapper cache) — **add the listener registry the same way**:

```rust
// crates/js/src/dom/mod.rs — extend the existing DomState
#[derive(Trace, Finalize, JsData)]
pub(crate) struct DomState {
    #[unsafe_ignore_trace] pub doc: SharedDoc,
    pub cache: boa_gc::GcRefCell<HashMap<u32, JsObject>>,           // M2 (unchanged)

    // --- E4-M3 additions ---
    /// (NodeId.index(), event type) -> ordered listeners. The `JsObject`s are
    /// callables; they are GC-traced (NOT ignored) so they stay rooted across the
    /// quiescence loop. `String` keys are `Trace`; `JsObject` values are `Trace`.
    pub listeners: boa_gc::GcRefCell<HashMap<(u32, String), Vec<JsObject>>>,

    /// The bounded virtual-time timer queue (§3). Holds callable JsObjects → traced.
    pub timers: boa_gc::GcRefCell<TimerQueue>,
}
```

`HashMap<(u32, String), Vec<JsObject>>` derives `Trace` because `(u32, String)` and `JsObject` are
`Trace` (Boa's `Trace` is implemented for std collections of `Trace` values). The cache pattern
already proves a `GcRefCell<HashMap<.., JsObject>>` field inside `DomState` traces correctly.

> **Key = `(NodeId.index(): u32, type: String)`**, NOT per-node objects. `NodeId.index()`
> (`dom/lib.rs:16`) is the stable `u32` arena index used by the M2 cache. `window` and `document`
> both map onto the arena **root** `NodeId` (index 0) — §1.4 distinguishes them with a reserved
> pseudo-id for `window`.

### 1.2 The registration methods

`addEventListener(type, handler)` and `removeEventListener(type, handler)` are **native methods on
the `Node` class** (so every node, `document`, and — via §1.4 — `window` have them). Pinned shapes:

```rust
// crates/js/src/dom/event.rs (new module; node::init wires the methods)
fn add_event_listener(this: &JsValue, args: &[JsValue], ctx: &mut Context) -> JsResult<JsValue> {
    let h = NodeHandle::from_this(this)?;                      // the target node (or window proxy)
    let ty = arg_str(args, 0, ctx)?;                          // event type, e.g. "click", "load"
    let cb = match args.get(1).and_then(|v| v.as_object()) {
        Some(o) if o.is_callable() => o.clone(),
        // non-callable handler (or EventListener object): per spec, an object with a
        // `handleEvent` method is allowed — DEFERRED (§8). A non-callable → silently ignored
        // (spec: a null/undefined listener is a no-op; we no-op non-callables too).
        _ => return Ok(JsValue::undefined()),
    };
    let key = (event_target_index(&h), ty);                   // (u32, String); §1.4 for window
    if let Some(state) = ctx.realm().host_defined().get::<DomState>() {
        let mut map = state.listeners.borrow_mut();
        let v = map.entry(key).or_default();
        // SPEC DEDUP: addEventListener with the same (type, callback, capture) is a no-op
        // if already present. We have no capture flag (target-phase) → dedup on callback identity.
        if !v.iter().any(|c| c == &cb) { v.push(cb); }        // `==` is JsObject ptr identity
    }
    Ok(JsValue::undefined())
}

fn remove_event_listener(this: &JsValue, args: &[JsValue], ctx: &mut Context) -> JsResult<JsValue> {
    let h = NodeHandle::from_this(this)?;
    let ty = arg_str(args, 0, ctx)?;
    let cb = args.get(1).and_then(|v| v.as_object());
    let key = (event_target_index(&h), ty);
    if let (Some(cb), Some(state)) = (cb, ctx.realm().host_defined().get::<DomState>()) {
        if let Some(v) = state.listeners.borrow_mut().get_mut(&key) {
            v.retain(|c| c != &cb);                           // identity match; unknown → no-op
        }
    }
    Ok(JsValue::undefined())
}
```

**Decisions:**
- **Dedup ON** (spec-faithful): adding the *same* callable for the *same* type twice registers it
  once. Identity is `JsObject` pointer equality. (Note in §8: with no capture flag, dedup is on
  `(type, callback)` only.)
- **`removeEventListener` of an unknown/never-added handler → no-op** (no error). Identity match by
  the same `JsObject` reference (the spec requirement).
- A non-callable second argument → **no-op** (no throw), matching the spec's null-listener case;
  the `handleEvent`-object form is deferred (§8).

### 1.3 Wiring into the `Node` class

Add to `node::init` (`crates/js/src/dom/node.rs:13`):
```rust
method(class, "addEventListener", 2, event::add_event_listener);
method(class, "removeEventListener", 2, event::remove_event_listener);
method(class, "dispatchEvent", 1, event::dispatch_event);   // §2
```
This gives every wrapper (elements, text, `document`) the three methods. No prototype split needed
(the M2 single-`Node`-class design already shares one prototype).

### 1.4 `window` as an EventTarget (the `load` event lives here)

Today `window === globalThis` (the realm global object), NOT a `Node` wrapper, so it has **no**
`addEventListener`. Two clean options:

- **(a) Reserve a pseudo-id for window; expose the three methods on the global.** `window` keeps
  being the global object, but we register **three global functions** `addEventListener` /
  `removeEventListener` / `dispatchEvent` that key into the listener map under a **reserved
  sentinel index** `WINDOW_KEY: u32 = u32::MAX` (no real `NodeId` can be `u32::MAX` — the arena is
  far smaller). A bare `addEventListener(...)` at top level (which the global provides) and
  `window.addEventListener(...)` both hit these, targeting `WINDOW_KEY`. **Chosen** — minimal, and
  matches that `window.addEventListener('load', …)` is the canonical idiom.

- (b) Make `window` a `Node` wrapper over the root. Rejected: `window === globalThis` is relied on
  by M1 tests (`window_is_global_this`) and scripts; changing it churns globals.

```rust
// globals.rs: after dom::install, also register window-level EventTarget methods.
fn install_window_events(ctx: &mut Context) {
    let f = NativeFunction::from_fn_ptr(event::window_add_listener);   // keys WINDOW_KEY
    let _ = ctx.register_global_callable(js_string!("addEventListener"), 2, f);
    // removeEventListener, dispatchEvent likewise.
}
```
`event_target_index(&NodeHandle)` returns `h.id.index()`; the window-level fns hard-code
`WINDOW_KEY`. `document` uses the root node's real index (0). (`document` ≠ `window` is preserved:
`document.addEventListener('DOMContentLoaded', …)` keys `(0, "DOMContentLoaded")`;
`window.addEventListener('load', …)` keys `(u32::MAX, "load")`.)

### 1.5 Borrow discipline (critical — no re-entrant `RefCell`/`GcRefCell` panic)

A method holds `ctx.realm().host_defined().get::<DomState>()` (a `GcRef`) only to **read/clone the
relevant listener `Vec` or push one entry**, then **drops it before any JS re-entry**. Crucially,
firing a listener (§2) **must not** be done while the `listeners` `GcRefCell` is borrowed —
`dispatchEvent` **snapshots** the listener `Vec` (clone of the `Vec<JsObject>`), drops every
borrow, then calls each. A listener may itself `addEventListener`/`removeEventListener` (mutating
the map) — safe because we iterate a **snapshot** (§2.3). Likewise the arena `RefCell` is **not**
borrowed across a listener call (listeners run arbitrary JS that re-borrows the arena via node
methods). This mirrors M2's "never call back into JS while holding a borrow" rule, now made real
because events DO call back into JS.

## 2. `dispatchEvent` + the `Event` object

### 2.1 The `Event` object — a plain Boa object (no native class)

An `Event` is a small `JsObject` built with `ObjectInitializer` (like `location`/`classList`), NOT
a native class — it carries no arena handle, only JS-visible state + two methods. M3 fields:

| member | kind | value |
|---|---|---|
| `type` | data, read-only | the event type string (`"click"`, `"load"`, …) |
| `target` | data | the node the event was dispatched on (a wrapper) — set at dispatch (§2.2) |
| `currentTarget` | data | the node whose listeners are currently running — updated per node during bubble |
| `defaultPrevented` | accessor (get) | reads an internal flag |
| `bubbles` | data, read-only | `true` for `load`/`DOMContentLoaded`/`click` we synthesize (cheap; informational) |
| `preventDefault()` | method | sets the internal `defaultPrevented` flag |
| `stopPropagation()` | method | sets an internal `stopped` flag → halts bubbling (§2.4) |

The internal flags (`defaultPrevented`, `stopped`) are stored as **own properties** on the event
object under non-enumerable internal keys (e.g. `__sf_prevented`, `__sf_stopped`) — simplest in
0.21.1 without a native data class. `preventDefault`/`stopPropagation` are
`NativeFunction::from_copy_closure_with_captures` capturing nothing, writing the flag via
`this.set(js_string!("__sf_stopped"), true, false, ctx)`. (Alternatively a tiny native-data
`EventData { prevented: Cell<bool>, stopped: Cell<bool> }` carried like `NodeHandle` — but the
own-property approach avoids a second class; **chosen: own-property flags**.)

A constructor `new Event(type)` is **optional** (note §8). For M3 we **mint Event objects
internally** when firing `load`/`DOMContentLoaded`/inline handlers, and accept a script-built event
on `dispatchEvent` — which can be **any object with a `type` property** (§2.5 coercion), so a
script-side `Event` constructor isn't required. If cheap, expose a global `Event` constructor that
builds the same object; **decision: expose a minimal `Event` constructor** (a global callable
returning the object above) so `new Event('x')` / `dispatchEvent(new Event('x'))` work — it's ~15
lines reusing the builder.

### 2.2 `dispatchEvent(node, event)` — set target, run listeners (target + optional bubble)

```rust
fn dispatch_event(this: &JsValue, args: &[JsValue], ctx: &mut Context) -> JsResult<JsValue> {
    let h = NodeHandle::from_this(this)?;               // dispatch target
    let event = coerce_event(args.get(0), ctx)?;        // §2.5: a JsObject with a `type`
    let ty = event.get(js_string!("type"), ctx)?.to_string(ctx)?.to_std_string_escaped();

    // target = currentTarget = this (the dispatch node), per spec.
    let target = this.clone();
    event.set(js_string!("target"), target.clone(), false, ctx)?;

    fire_at(&h, &ty, &event, this, ctx);                // target-phase listeners (§2.3)

    // OPTIONAL BUBBLE (cheap): walk parent chain, firing each node's listeners for `ty`,
    // until root or stopPropagation(). target stays the dispatch node; currentTarget updates.
    if bubbles(&event, ctx) {
        let mut cur = h.shared.borrow().parent(h.id);   // snapshot first parent, drop borrow
        while let Some(pid) = cur {
            if is_stopped(&event, ctx) { break; }
            let ph = NodeHandle { shared: h.shared.clone(), id: pid };
            let pwrapper = wrap_node(pid, ctx)?.into();  // currentTarget = this parent
            fire_at(&ph, &ty, &event, &pwrapper, ctx);
            cur = h.shared.borrow().parent(pid);         // re-borrow briefly, drop
        }
        // window also gets bubbled load/DOMContentLoaded? — for the load sequence those are
        // dispatched directly on window/document (§4), so no extra window bubble here.
    }
    // return !defaultPrevented (spec: dispatchEvent returns false if a listener canceled it).
    Ok(JsValue::from(!is_prevented(&event, ctx)))
}
```

### 2.3 `fire_at` — snapshot then run, catching listener errors (non-fatal)

```rust
fn fire_at(h: &NodeHandle, ty: &str, event: &JsObject, current: &JsValue, ctx: &mut Context) {
    // Snapshot the listener list for (id, ty), then DROP the host-defined borrow.
    let listeners: Vec<JsObject> = match ctx.realm().host_defined().get::<DomState>() {
        Some(state) => state.listeners.borrow()
            .get(&(event_target_index(h), ty.to_string()))
            .cloned().unwrap_or_default(),
        None => Vec::new(),
    };                                                  // borrow dropped here
    // currentTarget = the node whose listeners run now.
    let _ = event.set(js_string!("currentTarget"), current.clone(), false, ctx);
    for cb in listeners {                               // iterate the SNAPSHOT (M2 §safe)
        if is_stopped(event, ctx) { break; }           // stopPropagation also halts same-node? no
        // call cb with this=current node, arg = event. A throw is CAUGHT (non-fatal).
        let _ = cb.call(current, &[event.clone().into()], ctx);
    }
}
```

- **`this` inside a listener = the node it was registered on** (`current`), arg `[event]` — per
  spec. `JsObject::call(this, &[event], ctx)` (verified §0.3).
- **Listener throw → caught** (`let _ = cb.call(...)`). It is **non-fatal**; remaining listeners
  still run. (Optionally we record it into `ScriptOutcome.errors`; §4.5 routes a top-level
  collector — but a simple `let _ =` is the floor: never propagate, never panic.)
- **Snapshot iteration** means `removeEventListener` during dispatch doesn't invalidate the loop
  (the removed listener, if already snapshotted, still runs this dispatch — spec actually says a
  removed-during-dispatch listener should NOT run; we accept the snapshot simplification — note
  §8). `addEventListener` during dispatch won't run until the next dispatch (also acceptable).
- `stopPropagation()` halts **bubbling** (checked between nodes, §2.2) — we do **not** also stop
  remaining same-node listeners (that's `stopImmediatePropagation`, out of scope; note §8).

### 2.4 Bubbling decision — **optional, included because cheap**

Target-phase is mandatory. Bubbling is a ~10-line parent-chain walk (§2.2) reusing
`doc.parent(id)`; **included** (it makes `el.addEventListener('click', …)` on a container catch a
child's dispatched click — a common idiom). **Capture phase is OUT** (note §8): all listeners run
in the bubble/target order only. `event.eventPhase` is not modeled (or a constant). If bubble
proves fiddly in impl, target-only is the documented fallback — but it's cheap, so ship bubble.

### 2.5 Coercion of the `dispatchEvent` argument

```rust
fn coerce_event(arg: Option<&JsValue>, ctx: &mut Context) -> JsResult<JsObject> {
    match arg.and_then(|v| v.as_object()) {
        Some(o) => Ok(o.clone()),                       // any object; we read its `type`
        None => Err(JsNativeError::typ()
            .with_message("dispatchEvent: argument is not an Event").into()),
    }
}
```
A non-object (string/number/undefined) → **throws `TypeError`** (caught non-fatal). An object
without a `type` property → `type` reads as `"undefined"` → fires listeners for type
`"undefined"` (none, typically) — harmless. (Spec wants a real `Event`; the pragmatic coercion
accepts any object so a script need not use our constructor.)

## 3. The timer queue — bounded virtual time

### 3.1 `TimerQueue` (host-defined, GC-traced)

```rust
// crates/js/src/dom/timer.rs (new module)
use boa_engine::{JsObject, Finalize, Trace};

#[derive(Trace, Finalize)]
pub(crate) struct Timer {
    #[unsafe_ignore_trace] pub id: u64,
    #[unsafe_ignore_trace] pub due_ms: u64,          // virtual time the callback is due
    #[unsafe_ignore_trace] pub interval: Option<u64>, // Some(period) for setInterval, None for setTimeout
    pub callback: JsObject,                          // callable → GC-TRACED (NOT ignored)
    #[unsafe_ignore_trace] pub extra_args: (),       // M3: no extra-args forwarding (note §8)
}

#[derive(Trace, Finalize, Default)]
pub(crate) struct TimerQueue {
    pub timers: Vec<Timer>,                          // unsorted; drained in due-time order (§3.3)
    #[unsafe_ignore_trace] pub next_id: u64,         // monotonic id allocator (starts at 1)
    #[unsafe_ignore_trace] pub now_ms: u64,          // the virtual clock (starts at 0)
    #[unsafe_ignore_trace] pub callbacks_run: u32,   // bound counter (§3.4)
}
```
`TimerQueue` lives inside `DomState` as `timers: GcRefCell<TimerQueue>` (§1.1). The `callback`
field is **traced** so a `setTimeout`'d closure isn't collected before it runs. Everything else is
plain data (`unsafe_ignore_trace`). The whole queue is dropped when `run_scripts` returns.

### 3.2 `setTimeout`/`setInterval`/`clearTimeout`/`clearInterval` — global native fns

Boa has **no host timer** — we register native fns that enqueue into OUR queue (NOT Boa's job
queue; Boa jobs are FIFO microtasks with no delay/time model, unsuitable for `ms`/intervals/clear).
Registered in `globals::install` via `register_global_callable`:

```rust
// closures capture nothing GC; they read DomState from host_defined.
fn set_timeout(_t: &JsValue, args: &[JsValue], ctx: &mut Context) -> JsResult<JsValue> {
    let cb = match args.get(0).and_then(|v| v.as_object()) {
        Some(o) if o.is_callable() => o.clone(),
        // setTimeout("code string", ms) — eval-string form is DEFERRED (§8); non-callable → no-op id.
        _ => return Ok(JsValue::from(0)),
    };
    let ms = args.get(1).map(|v| v.to_number(ctx).unwrap_or(0.0).max(0.0) as u64).unwrap_or(0);
    let id = enqueue_timer(ctx, cb, ms, None);          // None = one-shot
    Ok(JsValue::from(id as f64))                        // numeric id (spec: a number)
}
fn set_interval(/* same */) -> JsResult<JsValue> { /* enqueue_timer(ctx, cb, ms, Some(ms)) */ }
fn clear_timeout(_t, args, ctx) -> JsResult<JsValue> {  // also serves clearInterval
    let id = args.get(0).map(|v| v.to_number(ctx).unwrap_or(0.0) as u64).unwrap_or(0);
    if let Some(s) = ctx.realm().host_defined().get::<DomState>() {
        s.timers.borrow_mut().timers.retain(|t| t.id != id);   // unknown id → no-op
    }
    Ok(JsValue::undefined())
}

fn enqueue_timer(ctx: &mut Context, cb: JsObject, delay_ms: u64, interval: Option<u64>) -> u64 {
    let Some(s) = ctx.realm().host_defined().get::<DomState>() else { return 0 };
    let mut q = s.timers.borrow_mut();
    q.next_id += 1;
    let id = q.next_id;
    let due = q.now_ms.saturating_add(delay_ms);        // due relative to CURRENT virtual time
    q.timers.push(Timer { id, due_ms: due, interval, callback: cb, extra_args: () });
    id
}
```
- `clearTimeout` and `clearInterval` are the **same** native fn (ids share one space) — spec allows
  cross-clearing. Unknown id → **no-op**.
- `setTimeout(fn, 0)` → `due_ms = now_ms` → runs in the next drain step (after current microtasks).
- A negative / `NaN` / missing `ms` → clamped to `0`.
- A non-callable first arg (or the `setTimeout("string")` form) → **no-op, returns id 0** (the
  eval-string form is a deferred non-goal, §8).

### 3.3 Draining in virtual-time order

The queue is drained **lowest `due_ms` first** (ties: lowest `id`, i.e. registration order). On
each step: pick the min-due timer, **advance the virtual clock** to its `due_ms` (no real sleep),
remove it (one-shot) or re-enqueue it (`due_ms += interval` for `setInterval`), then **call its
callback** with `this = undefined` (or `window`) and no args, catching throws; then run microtasks
(§4). Picking the min each step (O(n) scan) is fine for the small one-shot queues; no heap needed.

### 3.4 The bound — terminate `setInterval`

Two independent caps; hitting **either** stops the drain:
```rust
const MAX_TIMER_CALLBACKS: u32 = 10_000;   // total timer callbacks run
const MAX_VIRTUAL_MS:      u64 = 10_000;    // virtual clock ceiling (10 virtual seconds)
```
- Before running a timer, if `callbacks_run >= MAX_TIMER_CALLBACKS` **OR** the min-due timer's
  `due_ms > MAX_VIRTUAL_MS`, **stop draining** (leave remaining timers undrained).
- A `setInterval(fn, 100)` re-enqueues at `now+100` each fire; the virtual clock advances 100 per
  fire, so it hits `MAX_VIRTUAL_MS` after ~100 fires and stops — **bounded, no hang**.
- A `setInterval(fn, 0)` (zero-delay interval) does NOT advance the clock, so the **callback-count**
  cap (`MAX_TIMER_CALLBACKS`) is what terminates it. Both caps together guarantee termination.
- **When the bound is hit:** stop draining; remaining timers are **silently dropped** (optionally
  push one `ScriptError`/console note "timer budget exhausted, N timers dropped" — recommended for
  diagnostics, §4.5). Never panic, never loop forever.

## 4. The run-to-quiescence loop (the heart of M3)

Inserted in `run_scripts` **after the script-eval loop, before `drop(ctx)`** (§0.2). Precise
ordering:

```rust
// after: for src in scripts { ctx.eval(...) }   // initial scripts done

// (a) Drain microtasks from the initial scripts (Promise .then reactions, queued during eval).
run_microtasks(&mut ctx, &mut errors);            // ctx.run_jobs(); catch Err

// (b) Fire DOMContentLoaded on document, then load on window — to their listeners + inline on*.
fire_lifecycle_event(&mut ctx, DOCUMENT_ROOT_INDEX, "DOMContentLoaded", &mut errors);
run_microtasks(&mut ctx, &mut errors);            // a DCL handler may schedule microtasks
fire_lifecycle_event(&mut ctx, WINDOW_KEY,         "load",             &mut errors);
run_microtasks(&mut ctx, &mut errors);

// (c) Drain the bounded timer queue in virtual-time order; microtasks after EACH callback.
loop {
    // pick min-due timer; check bounds (§3.4); advance clock; pop/re-enqueue; call cb.
    let Some(step) = next_due_timer(&mut ctx) else { break };   // None => empty or bound hit
    let _ = step.callback.call(&JsValue::undefined(), &[], &mut ctx);  // throw caught
    run_microtasks(&mut ctx, &mut errors);         // interleave: microtasks after every timer
}
// (the timer loop also re-checks bounds each iteration; see next_due_timer)

// THEN: drop(ctx); reclaim arena (UNCHANGED from M1/M2).
```

### 4.1 `fire_lifecycle_event`

Builds an internal `Event { type, target }` (§2.1), sets `target`/`currentTarget` to the
document/window, and runs the listeners registered under `(DOCUMENT_ROOT_INDEX=0, "DOMContentLoaded")`
/ `(WINDOW_KEY, "load")` via `fire_at` (§2.3) — **plus** the inline `on*` handlers (§6) for that
event. These events do **not** bubble through the arena (they're dispatched at document/window
directly), so no parent walk. A listener added during the initial scripts (the common
`document.addEventListener('DOMContentLoaded', …)`) fires here; one added by a *timer* callback
after `load` already fired will simply never fire (correct — the event is past).

### 4.2 `next_due_timer` (the bounded picker)

```rust
fn next_due_timer(ctx: &mut Context) -> Option<TimerStep> {
    let s = ctx.realm().host_defined().get::<DomState>()?;
    let mut q = s.timers.borrow_mut();
    if q.callbacks_run >= MAX_TIMER_CALLBACKS { return None; }     // count bound
    // find min (due_ms, id)
    let idx = q.timers.iter().enumerate()
        .min_by_key(|(_, t)| (t.due_ms, t.id))?.0;
    if q.timers[idx].due_ms > MAX_VIRTUAL_MS { return None; }      // virtual-time bound
    let t = &q.timers[idx];
    let cb = t.callback.clone();
    q.now_ms = t.due_ms;                                           // advance virtual clock
    q.callbacks_run += 1;
    match t.interval {
        Some(period) => { let due = q.now_ms.saturating_add(period.max(1)); q.timers[idx].due_ms = due; }
        None => { q.timers.remove(idx); }                          // one-shot: consume
    }
    Some(TimerStep { callback: cb })
}                                                                 // borrow dropped before cb.call
```
The `GcRefCell` borrow is **dropped before** the caller invokes `cb.call(...)` (the `TimerStep`
owns a clone of the callback). A callback that schedules **another** `setTimeout` pushes into the
queue; the next loop iteration picks it up — **nested timers drain** until empty or bounded. Note
`period.max(1)` prevents a zero-delay interval from never advancing the clock (so the count bound
plus a +1ms-per-fire floor both bound it; choose count bound as the primary terminator for
zero-delay — `period.max(1)` is a belt-and-suspenders so virtual time also creeps up).

### 4.3 `run_microtasks`

```rust
fn run_microtasks(ctx: &mut Context, errors: &mut Vec<ScriptError>) {
    if let Err(e) = ctx.run_jobs() {                               // verified §0.3
        errors.push(ScriptError { message: format!("{e}"), src: None });
    }
}
```
`ctx.run_jobs()` drains Boa's promise-reaction queue to empty (or until a job throws — caught).
Promise `.then` callbacks run here. We interleave it after every timer + every lifecycle event so a
`.then` that mutates the DOM is reflected before the next step (and before the final render).

### 4.4 Ordering summary (the contract)

1. initial `<script>`s eval (M1/M2) → 2. microtasks → 3. `DOMContentLoaded` (document) →
4. microtasks → 5. `load` (window) → 6. microtasks → 7. timer drain loop {min-due timer →
microtasks} until empty or bound → 8. `drop(ctx)` → 9. clone-out final arena → 10. style/layout/
paint the final DOM (paint unchanged, §5).

### 4.5 Error routing

`fire_at`/timer/microtask throws are caught. The minimal floor is `let _ = …` (never propagate).
**Recommended:** thread the existing `errors: Vec<ScriptError>` (already in `run_scripts`) into the
loop so a thrown listener/timer/microtask, and a "timer budget exhausted" note, land in
`ScriptOutcome.errors` (visible via `report_console` in paint). This needs no signature change —
the loop runs inside `run_scripts` where `errors` is in scope.

## 6. inline `on*` handlers — IN (cheap)

### 6.1 Decision: support inline handlers as listeners (compiled from the attribute string)

`<body onload=…>`, `<svg onload=…>`, `<button onclick=…>`, `<div onclick=…>` etc. Without real
input, only **load-ish** inline handlers fire automatically (`onload`, `onclick` only if a script
`dispatchEvent`s a click). It's cheap and makes `<body onload="…">` pages work, so **IN**.

### 6.2 Implementation — compile the attribute as a function, treat as a listener at fire time

When firing an event of type `T` on node `N` (in `fire_at` / `fire_lifecycle_event`), **also**
check `N`'s `on<T>` attribute (e.g. `onload`, `onclick`, `onclick`). If present and non-empty,
**compile it once** as a function body and call it:

```rust
// inside fire_at, after running registered listeners (or before — spec: inline handler is an
// "early" listener; order vs addEventListener is subtle. M3: run inline handler FIRST, then
// addEventListener listeners — matches the common case; note §8 for exact ordering.)
fn run_inline_handler(h: &NodeHandle, ty: &str, event: &JsObject, current: &JsValue, ctx: &mut Context) {
    let attr = format!("on{ty}");
    let body = { h.shared.borrow().get_attribute(h.id, &attr).map(str::to_string) };  // drop borrow
    let Some(body) = body.filter(|b| !b.trim().is_empty()) else { return };
    // Compile `(function(event){ <body> })` once and call with this=current, arg=event.
    // Simplest robust path in 0.21.1: eval a function expression, then call the result.
    let src = format!("(function(event){{ {body} \n}})");
    if let Ok(JsValue::Object(f)) = ctx.eval(Source::from_bytes(src.as_bytes())) {
        let _ = f.call(current, &[event.clone().into()], ctx);     // throw caught, non-fatal
    }
    // a compile error in the attribute → eval Err → caught, non-fatal.
}
```
- **`window`/`document` lifecycle:** `onload` is conventionally on `<body>` (HTML maps
  `<body onload>` to the **window** `load` event). So `fire_lifecycle_event(.., WINDOW_KEY,
  "load")` must also scan the **`<body>` element's `onload` attribute** (and `<html>`/`<frameset>`
  per spec; M3: just `<body>`). `DOMContentLoaded` has no inline-attribute form (there is no
  `onDOMContentLoaded` content attribute) — so step (b)'s DCL fires only registered listeners; the
  `<body onload>` is fired with `load`.
- Compiling per-fire (re-eval each dispatch) is acceptable for one-shot (handlers fire ≤ a handful
  of times). A one-shot `onload` compiles exactly once. (A cache keyed by `(NodeId, attr)` is a
  trivial future optimization — not built.)

### 6.3 No-script page with an inline `<body onload>` — the early-return caveat

`run_scripts` early-returns when there are **zero `<script>`s** (`lib.rs:81`). A page like
`<body onload="…">` with no `<script>` would skip the whole JS phase → its `onload` never fires.
**Decision:** extend the early-return guard to also check for **any element with an `on*` attribute
the load sequence fires** (cheaply: a `has_inline_load_handler(doc)` DFS looking for a `<body>`/
element with an `onload`/`on*` attribute), OR — simpler — **always build the Context when the doc
has any element bearing an `on*` attribute**. Pragmatic minimal: in `collect_scripts`'s caller,
if `scripts.is_empty()` but `doc_has_inline_handler(doc)`, still run the quiescence loop (with no
scripts evaluated). This keeps the common script-free page at **zero overhead** (no `on*` attrs →
no Context) while honoring `<body onload>`. *If this is judged too fiddly, the documented fallback
is: inline handlers only fire when at least one `<script>` exists (note §8).* Recommend the cheap
DFS guard.

## 7. Error / edge handling + bounds (never panic, no real time/threads)

- **Listener / timer / microtask throws → caught, non-fatal, continue** (`let _ = cb.call(...)` /
  `run_jobs()` Err captured). Remaining listeners/timers still run; the page renders with whatever
  committed before the throw.
- **`setInterval` that never clears → bounded** by `MAX_TIMER_CALLBACKS` + `MAX_VIRTUAL_MS` (§3.4).
  Hitting the bound stops the drain (remaining timers dropped, optional note). **No hang, ever.**
- **`clearTimeout`/`clearInterval` of an unknown id → no-op.** Cross-clearing (clearInterval on a
  setTimeout id) works (one id space).
- **`addEventListener` twice with the same fn → deduped** (spec; identity = `JsObject` ptr eq).
  Different fn objects with the same source → two listeners (correct).
- **`removeEventListener` with a never-added / different fn → no-op.** During-dispatch removal:
  snapshot iteration means it may still run this dispatch (documented simplification, §2.3/§8).
- **`dispatchEvent(non-Event)`** — non-object → `TypeError` (caught); object without `type` →
  fires type `"undefined"` (harmless).
- **Re-entrancy:** no `GcRefCell`/`RefCell` borrow is held across a JS call (listeners/timers
  re-borrow arena + registries freely). Snapshots taken, borrows dropped (§1.5).
- **No real time / threads:** the virtual clock (`now_ms`) starts at 0 and advances only to the
  next due timer's time; **no `sleep`, no wall-clock, no threads.** Deterministic, reproducible.
- **`run_scripts` stays infallible:** never returns `Err`, never panics; all failures are values in
  `ScriptOutcome.errors` (or silently dropped per the floor). The M1/M2 clone-out + no-panic
  guarantees hold: the loop only mutates the same `shared` arena and uses caught calls.
- **NodeId validity:** ids never invalidated (arena only grows); a listener keyed to a node later
  detached still exists in the map (minor leak until `run_scripts` ends) — `fire_at` only fires it
  if something dispatches on that id. Acceptable for one-shot.

## 8. Edge cases & non-goals (deliberate)

**Delivered:** `addEventListener`/`removeEventListener`/`dispatchEvent` (target phase + cheap
bubble), minimal `Event` (`type`/`target`/`currentTarget`/`defaultPrevented`/`bubbles` +
`preventDefault`/`stopPropagation`) + a minimal `Event` constructor; `DOMContentLoaded` (document)
+ `load` (window) fired after scripts; inline `on*` handlers (compiled-as-listener, `<body onload>`
mapped to window `load`); `setTimeout`/`setInterval`/`clearTimeout`/`clearInterval` over a bounded
virtual clock; Promise microtasks via `ctx.run_jobs()`; the run-to-quiescence ordering.

**Non-goals (deferred / documented limits):**
- **No capture phase precision** — target + optional bubble only; `eventPhase`/capture flag/
  `stopImmediatePropagation`/`useCapture`/options object (`{capture, once, passive}`) **out**.
  *(`once` is cheap — a per-listener flag dropping the entry after first fire — but DEFERRED to keep
  the registry a plain `Vec<JsObject>`; note as the obvious next add.)*
- **No real input events** — `click`/`keydown`/`mousemove`/etc. fire **only** via script
  `dispatchEvent`; there is no input device.
- **No event default actions** — `preventDefault()` sets the flag (readable, returned by
  `dispatchEvent`) but there is **no default action** to cancel (no form submit, no link
  navigation, no checkbox toggle). The flag is observational only.
- **No `requestAnimationFrame`** — out. *(A bounded stub aliasing `setTimeout(cb, 16)` is a trivial
  future add; note. Not built — the brief lists rAF as optional/non-goal.)*
- **`setTimeout("code string", ms)`** (eval-string form) and **extra-args forwarding**
  (`setTimeout(fn, ms, a, b)`) — **out** (callable-only, no forwarded args).
- **EventListener object form** (`{handleEvent}` instead of a function) — out (callable handlers
  only).
- **`stopImmediatePropagation`**, `Event` subtypes (`MouseEvent`/`KeyboardEvent`/`CustomEvent`
  `detail`), `composedPath`, `relatedTarget`, `isTrusted` — out.
- **During-dispatch listener mutation** follows the **snapshot** semantics (a removed-during-dispatch
  listener may still run this dispatch; an added one runs next dispatch) — a documented divergence
  from the exact spec ordering.
- **Exact inline-handler vs addEventListener ordering** — M3 runs the inline `on*` handler then
  registered listeners (the common visible behavior); the spec's precise interleaving (inline
  handler occupies a position in the listener list by when the attribute was set) is **not**
  modeled.
- **No `MutationObserver`, no `queueMicrotask` host hook** beyond Boa's own job queue, no
  `Promise`/async semantics beyond what `ctx.run_jobs()` drains.
- **No-script + no-inline-handler page → zero overhead** (early return; no Context) — preserved.

## 9. Test plan (concrete)

`js` crate unit tests drive `run_scripts` directly (returns `ScriptOutcome` + mutates `doc`);
visual tests go through `render_document` and assert pixels. Reuse M1/M2 helpers (`run(html)`,
`log_of(html)`, `find_id`).

**Events:**
1. **addEventListener + dispatchEvent fires it** (console proof):
   `el.addEventListener('x', () => console.log('fired')); el.dispatchEvent(new Event('x'))` →
   console has `"fired"`. `event.target === el` (log `e.target===el`).
2. **removeEventListener stops it:** add then remove the **same** fn, dispatch → no `"fired"`.
   Removing a *different* fn → still fires (identity).
3. **dedup:** `addEventListener('x', f)` twice (same `f`), dispatch once → `"fired"` logged
   **once**.
4. **listener `this` + arg:** handler logs `this===el` and `e.type==='x'` → both `true`/`x`.
5. **bubble:** `parent.addEventListener('x', …)`; `child.dispatchEvent(new Event('x'))` (bubbles)
   → parent's listener runs; `e.currentTarget` is parent during its run, `e.target` is child.
   `stopPropagation()` in the child listener → parent listener does NOT run.
6. **throwing listener is non-fatal:** a listener throws; a second listener + the rest of the page
   still run/render; `outcome.errors` records the throw (if routed).

**Load sequence:**
7. **DOMContentLoaded fires after scripts:** a script does
   `document.addEventListener('DOMContentLoaded', () => { document.body.style.background='#00ff00' })`
   → after `run_scripts`, the body's `style` attr has the green (and visually paints green, §VISUAL).
8. **`load` on window:** `window.addEventListener('load', () => console.log('loaded'))` →
   `"loaded"` in console.
9. **inline `<body onload>`:** `<body onload="document.body.setAttribute('data-x','1')">` (with or
   without a script) → after run, `<body>` has `data-x=1`. Inline `<button onclick>` fires when a
   script dispatches a click on it.

**Timers:**
10. **setTimeout(fn,0) runs + mutates DOM before render (VISUAL):**
    `setTimeout(() => { document.getElementById('b').style.background='#ff0000' }, 0)` → the
    rendered pixel of `#b` is **red** (proves the timer drained before paint).
11. **setInterval bounded:** `var n=0; var id=setInterval(()=>{ if(++n>=1000000) clearInterval(id) }, 0)`
    → does NOT hang; `n` stops at `MAX_TIMER_CALLBACKS` (assert `n <= 10000`); test completes fast.
12. **clearTimeout cancels:** `var id=setTimeout(()=>console.log('no'),5); clearTimeout(id)` → no
    `"no"`. `clearTimeout(99999)` (unknown) → no error.
13. **nested setTimeout drains:** `setTimeout(()=>{ setTimeout(()=>console.log('inner'),0) },0)` →
    `"inner"` logged (the queue drains the dynamically-scheduled timer).
14. **virtual-time order:** schedule `setTimeout(a, 50)` then `setTimeout(b, 10)` → `b` runs before
    `a` (log order `"b" "a"`).
15. **throwing timer is non-fatal:** `setTimeout(()=>{throw 1},0); setTimeout(()=>console.log('ok'),0)`
    → `"ok"` still logged; page renders.

**Microtasks / Promises:**
16. **Promise .then microtask runs:** `Promise.resolve().then(()=>console.log('micro'))` → `"micro"`
    logged (drained by `ctx.run_jobs()` in the quiescence loop). A `.then` that mutates the DOM is
    reflected in the render.
17. **interleave:** a `setTimeout` whose callback resolves a promise whose `.then` logs → the
    `.then` runs before the next timer (ordering proof).

**Bounds / no-hang:**
18. **bound hit doesn't hang:** a `setInterval(fn, 1)` that never clears → the run terminates
    (virtual clock hits `MAX_VIRTUAL_MS`), `outcome` returns, page renders; assert wall-time is
    small.

**Visual (through `render_document`, assert pixels):**
19. (#10) timeout sets a background → pixel reflects it.
20. (#7) DOMContentLoaded handler recolors body → pixel reflects it.
21. **regression:** a script-free, handler-free page renders byte-identically to pre-M3 (early
